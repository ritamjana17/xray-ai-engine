# Sample X-rays

200 images (100 fractured, 100 normal), generated by `quantum/prepare_dataset.py`.
Don't add or edit files here by hand. Re-run the script instead, so that
`lib/samples.ts` and `manifest.csv` stay in sync.

* `fracatlas_fractured_###.jpg` / `fracatlas_normal_###.jpg`: 50 + 50 from FracAtlas
* `bonefx_fractured_###.jpg` / `bonefx_normal_###.jpg`: 50 + 50 from Bone Fracture Multi-Region
* `manifest.csv`: label, source, body region, train/test split and original filename for every image

Images are grayscale JPEG, max 512 px on the longest side.
